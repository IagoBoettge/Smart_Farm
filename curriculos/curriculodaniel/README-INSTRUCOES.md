# 📋 Template de Currículo - CSS Externo
## Trabalho Prático para Alunos

### 🎯 **Objetivo**
Criar um currículo profissional completo utilizando HTML semântico e CSS externo, aplicando conceitos avançados de layout, responsividade e design moderno.

- Estrutura HTML semântica completa
- Conteúdo de exemplo para orientação

### 2. **styles.css**
- 26 exercícios TODO numerados e organizados

## 🚀 **Como Começar**

### **Passo 1: Preparação**
1. Baixe os dois arquivos: `curriculo-template.html` e `styles.css`
2. Coloque ambos na mesma pasta no seu computador
3. Abra o arquivo HTML no navegador para ver a estrutura básica
4. Abra o `styles.css` no seu editor de código favorito

### **Passo 2: Desenvolvimento**
1. **Complete os TODOs em ordem sequencial** (TODO-01 até TODO-26)
2. **Teste cada seção** no navegador após implementar
3. **Use as sugestões** fornecidas nos comentários como base
4. **Personalize** cores, espaçamentos e efeitos conforme sua criatividade

## 🎨 **Conceitos CSS Aplicados**

### **Layout Moderno**
- **CSS Grid**: Layout principal em duas colunas
- **Flexbox**: Alinhamento de elementos
- **Position**: Timeline e elementos sobrepostos
- **Sticky**: Sidebar fixa durante scroll

### **Design Visual**
- **Gradientes**: Backgrounds coloridos
- **Box-shadow**: Elevação e profundidade
- **Border-radius**: Cantos arredondados
- **Transitions**: Animações suaves
- **Transform**: Efeitos hover

### **Responsividade**
- **Media Queries**: Adaptação para diferentes telas
- **Grid responsivo**: Colapso para mobile
- **Flexbox wrap**: Organização flexível
- **Unidades relativas**: rem, %, vh, vw

### **Tipografia e Cores**
- **Font weights**: Hierarquia visual
- **Color palette**: Esquema de cores consistente
- **Line-height**: Legibilidade otimizada
- **Letter-spacing**: Refinamento tipográfico

## 📱 **Recursos de Responsividade**

### **Desktop (> 968px)**
- Layout em duas colunas
- Sidebar fixa
- Timeline vertical completa
- Grid de projetos em múltiplas colunas

### **Tablet (768px - 968px)**
- Layout em coluna única
- Sidebar no topo
- Elementos reorganizados
- Botões adaptados

### **Mobile (< 640px)**
- Design totalmente vertical
- Foto centralizada
- Botões em largura total
- Espaçamentos reduzidos

## 💡 **Dicas de Sucesso**

### **Durante o Desenvolvimento**
1. **Teste constantemente**: Abra o arquivo no navegador após cada TODO
2. **Use as ferramentas do navegador**: F12 para inspecionar elementos
3. **Comece simples**: Implemente primeiro, depois personalize
4. **Mantenha organização**: Comente seu código adicional

### **Para Personalização**
1. **Cores**: Use ferramentas como [Coolors.co](https://coolors.co) para paletas
2. **Ícones**: Substitua emojis por ícones de [Font Awesome](https://fontawesome.com)
3. **Fontes**: Experimente fontes do [Google Fonts](https://fonts.google.com)
4. **Inspiração**: Visite [Dribbble](https://dribbble.com) para ideias de design

### **Resolução de Problemas**
1. **Elemento não aparece**: Verifique display, position, z-index
2. **Layout quebrado**: Confirme box-sizing: border-box
3. **Cores não funcionam**: Verifique especificidade CSS
4. **Responsividade**: Teste em diferentes tamanhos de tela
